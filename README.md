# Git Practice Project

## Project Overview

This project demonstrates Git and GitHub fundamentals through a simple Python calculator.

## Author

Amit Paul

## Features

- Addition, subtraction, and multiplication
- Division with division-by-zero handling
- Git commits and version control
- Branch creation, merging, and pushing to GitHub

## Technologies

- Python
- Git
- GitHub
