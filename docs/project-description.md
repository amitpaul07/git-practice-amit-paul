# Project Description

## Overview

This project is a practical Git and GitHub exercise using Python.

The purpose of this project is to demonstrate a basic version control workflow.

## Git Features Practiced

The project demonstrates:

- Git repository initialization
- Staging files
- Creating commits
- Creating branches
- Switching branches
- Merging branches
- Deleting merged branches
- Connecting a local repository to GitHub
- Pushing changes to GitHub

## Python Features

The project contains a simple calculator with functions for:

- Addition
- Subtraction
- Multiplication

## Project Structure

The Python source files are stored inside the `src` directory.

Documentation is stored inside the `docs` directory.
